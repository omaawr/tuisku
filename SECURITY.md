### Reporting a Vulnerability

You can report a vulnerability by going to the Security and quality tab (or making an issue) and it'll soon be fixed.. hopefully. maybe
This includes misuses with the Cipher library (built in java library) which is used to decrypt/encrypt notes with the ChaCha20 algorithm that supports Android 9 or later

A new version which includes a security patch might look something like `1.2.x` or `1.x.x-1` if nothing's really changed for the new release
